    🎨 Figma Template Automation System - Autonomous development powered by Miyabi AI framework

    🌟 Project Overview

    自動化されたWebアプリ/LPテンプレート生成システム。Figmaで30種類以上のテンプレートを管理し、ユーザーが選択したテンプレートに任意のテキスト・色・枠線を自動適用して量産できる仕組みを提供します。

    Tech Stack

    • Backend: Flask (Python 3.10+), JWT, Google Sheets API
    • Frontend: React 18+, Vite, TypeScript, Tailwind CSS
    • Figma Plugin: TypeScript, Figma Plugin API
    • AI Framework: Miyabi (Autonomous Operations)
