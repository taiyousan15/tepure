# UAT (User Acceptance Testing) チェックリスト

## 目的

本番環境リリース前に、全機能が要件通り動作することを確認する。

## テスト環境

- **Frontend**: https://tepure-preview.web.app
- **Backend API**: https://tepure-api-xxx.run.app
- **テストユーザー**: uat-user@example.com / TestPassword123!

## 1. 認証・認可

### 1.1 ログイン

- [ ] **正常系**: 正しいメール・パスワードでログイン成功
  - 期待: ダッシュボードにリダイレクト
  - JWT トークン発行確認

- [ ] **異常系**: 間違ったパスワードでログイン失敗
  - 期待: エラーメッセージ表示「認証に失敗しました」

- [ ] **異常系**: 存在しないメールアドレス
  - 期待: エラーメッセージ表示（汎化メッセージ）

### 1.2 トークンリフレッシュ

- [ ] アクセストークン期限切れ後、自動リフレッシュ
  - 期待: シームレスに継続使用可能

- [ ] リフレッシュトークン期限切れ後、再ログイン要求
  - 期待: ログイン画面にリダイレクト

### 1.3 ログアウト

- [ ] ログアウトボタンクリック
  - 期待: ログイン画面にリダイレクト
  - トークン無効化確認

### 1.4 権限制御

- [ ] 一般ユーザーで管理者機能アクセス試行
  - 期待: 403 Forbidden

- [ ] 管理者ユーザーで全機能アクセス
  - 期待: すべて正常動作

- [ ] 入力フィールドにスクリプトタグ入力

  - 期待: エスケープされて表示、実行されない

- [ ] 外部サイトから API 呼び出し試行
  - 期待: CORS エラー

### 9.4 SQL Injection対策

- [ ] 入力フィールドに SQL 文入力
