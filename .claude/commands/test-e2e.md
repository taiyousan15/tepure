# E2Eテスト実行コマンド

Playwrightを使用したE2Eテストを実行します。

## 実行内容

1. Playwrightブラウザの確認
2. E2Eテスト実行（全ブラウザ）
3. テストレポート表示

## オプション

- 全テスト実行（デフォルト）
- UI モード（対話的実行）
- デバッグモード
- 特定ブラウザのみ実行

## 使用例

```bash
# 全テスト実行
npm run test:e2e

# UI モード
npm run test:e2e:ui

# デバッグモード
npm run test:e2e:debug

# Chromium のみ
npm run test:e2e:chromium

# レポート表示
npm run test:e2e:report
```

## 要件

- フロントエンドサーバーが起動していること（自動起動も可能）
- Playwrightブラウザがインストール済みであること

## テストカバレッジ

- 認証フロー（ログイン・ログアウト）
- テンプレート閲覧（一覧・検索・フィルター）
- テンプレート使用（フォーム入力・送信）
- テンプレート登録（作成・バリデーション）
- モバイル対応
- アクセシビリティ
